# moondough — cookie shop site

Scroll-story site for moondough (Angeles City). Everything (logo, photos, fonts, scripts) is embedded in index.html — no other files needed.

## Deploy on GitHub Pages
1. Upload index.html (and this README) to the repository root.
2. Settings → Pages → Deploy from a branch → main / root.
3. Site goes live at https://<user>.github.io/<repo>/ in a minute or two.
